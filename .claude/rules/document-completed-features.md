# Document completed features

When a feature is complete, record it in the `CLAUDE.md` of the part it belongs to: `backend/CLAUDE.md`, `frontend/CLAUDE.md`, or the root `CLAUDE.md` for the shared frontend ↔ backend contract.

- One short sentence per feature, in the section listing what is implemented.
- Point to where the details live (files, modules or tests), e.g. "Coastal 3D city view: see `src/city/` and `tests/unit/map/cityLayout.test.ts`."
- Do not describe how it works: the code and its tests are the details.
- Update or remove the sentence when the feature changes or goes away.
